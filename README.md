# 2F 護理排班系統 V3.0

## 啟動方式

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 已內建規則

- 全職至少 8 天休假
- 郭珍君為兼職，只排 D 班，且剛好 10 天
- 最多連續上班 5 天
- 大夜固定 N → N → off → off
- E 後不可接 D
- D 可以接 N
- Meeting M 算上班，但不算臨床 D/E/N 人力
- R 預排休不可被覆蓋
- 自動嘗試多份班表並選最高分
- 彩色 Excel 匯出

## 檔案說明

- `app.py`：Streamlit 主介面
- `config.py`：所有規則與名單
- `loader.py`：Excel 匯入
- `scheduler.py`：排班核心
- `optimizer.py`：多次排班與評分
- `validator.py`：規則檢查
- `statistics.py`：統計表
- `exporter.py`：Excel 彩色匯出
- `utils.py`：日期與工具函式

## 注意

Excel 格式不需要完全固定，但系統需要能在列中找到護理師姓名與班別代號。
若排班結果仍有提醒，代表在目前人力、預排休與規則限制下，系統無法完全滿足所有條件，需要人工調整人力需求或預排條件。

## V24 穩定性重構

本版新增：

- 日期欄自動偵測，避免把「權限 D/E/N」誤讀為第一天班別。
- 支援跨月日期（如 29、30、1、2）。
- 支援姓名異體：林怡微/林怡薇、溫鈺羚/温鈺羚。
- `V` 休假統一轉為固定預排休 `R`，`開會` 轉為 `M`。
- 排班前輸入驗證與每日人力可行性預檢。
- 最佳結果改用硬性錯誤優先排序，不再讓公平性分數蓋過 Error。
- 有硬性錯誤時不再顯示「完全成功」。

啟動：

```bash
pip install -r requirements.txt
streamlit run app.py
```


## V26.4 請假管理
- 在系統中直接新增特休、病假、事假、公假、婚假、喪假、產假、陪產假、家庭照顧假、生理假、育嬰假、無薪假與其他假。
- 請假日期會自動轉為排班核心的 R，因此不會被安排 D/E/N。
- 最終班表顯示實際假別，不只顯示 R。
- Excel 會新增「請假紀錄」工作表。
- 若請假造成當日最低人力無法達成，會在排班前提醒。


## V26.4.3 最終班表配色調整
- D / E / N / M / R / off 與各類請假，在 Excel 最終班表中全部取消底色。
- 「班別權限」欄統一使用淺藍色底色與粗體黑字。
- 排班規則與演算法完全不變，只調整顯示方式。


## V26.4.4 最終班表問題紅色標示
- D/E/N 正常班別維持白底黑字。
- 班別權限維持淺藍底。
- 當日 D/E/N 實際人力只要「多於或少於最低需求」，人力統計格會標紅。
- 規則檢查若有指定人員與日期，最終班表對應格會標紅。
- 全月型問題（如休假不足、連續上班過長）會將該人姓名標紅。
- Streamlit 最終班表與下載 Excel 都會套用相同問題提示。


## V26.5 排班速度最佳化
- 改為「兩階段搜尋」：先快速產生候選，再只精修前幾名。
- 不再對每一次候選都執行 20 輪 Local Search。
- 新增早停機制：長時間沒有改善時自動停止。
- 得到 0 error 且 warning 很少時會提前結束。
- 新增三種速度模式：
  - ⚡ 快速：25 次候選 / 精修前 2 名 / 4 輪。
  - ⚖️ 平衡：50 次候選 / 精修前 3 名 / 8 輪。
  - 🎯 高品質：100 次候選 / 精修前 5 名 / 15 輪。
- 保留手動調整嘗試次數。
